# Bộ tài liệu làm slide

| Mục | File | Dùng để |
|---|---|---|
| 1 | `1-tong-hop-kien-thuc.docx` (bản sửa: `.md`) | Nắm toàn bộ kiến thức của bài, số liệu đã chốt, câu hỏi có thể gặp |
| 2 | `2-hinh-anh/` (13 hình) | Hình đưa vào slide; danh mục và slide dùng hình nằm ở mục 3 của kế hoạch |
| 3 | `3-ke-hoach-tao-slide.docx` (bản sửa: `.md`) | Chi tiết 13 slide, phân công, nguyên tắc thiết kế, các bước, checklist nộp |

Sửa nội dung trong file `.md` rồi tạo lại Word: `npm install && node md2docx.js 1-tong-hop-kien-thuc.md 1-tong-hop-kien-thuc.docx` (tương tự cho file 3).
